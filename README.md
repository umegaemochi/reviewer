ローカル環境での起動方法
1. リポジトリのクローン
git clone https://github.com/umegaemochi/reviewer.com
cd reviewer

2. バックエンドの起動
cd backend
./mvnw spring-boot:run

※ http://localhost:8080 で起動します。

3. フロントエンドの起動
cd frontend
npm install
npm run dev
